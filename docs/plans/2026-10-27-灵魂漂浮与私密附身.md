# 灵魂漂浮与私密附身

2026-10-27，SOUL-002，当前 AI 在用户指定 `fork` 分支实现。用户要求覆盖 SOUL-001 的“灵魂固定在遗体旁、远处可附身、附身后语音按位置转发”行为。

## 本轮行为

- 自由灵魂可用现有可配置移动键，在当前整张地图内快速漂浮，穿过地图实体，不消耗体力、不播放脚步声、不显示武器准星。默认正常步行 2 倍，面板可选 2/4/6/8 倍，即 7.4/14.8/22.2/29.6 米每秒。房主按输入、时间和地图边界计算位置，客户端仅预测显示。
- 原地停留可等待救援；靠近存活队友 **2.4 米三维距离**以内，面板才出现该队友的附身按钮。移出距离或目标死亡/变异/离线，选择提示消失。房主复核资格和距离，不能仅靠伪造按钮或目标 ID 从远处附身。
- 附身仍只共享视角，不控制队友身体。只有该灵魂和其附身的存活队友可以互通语音；旁边的其他活人或附身同一人的其他灵魂均听不到该灵魂，灵魂也听不到他们。活人之间仍沿用原距离语音。解除后立即恢复自由灵魂，位于队友当前的位置，双方语音切断。
- 新增漂浮、半透明青蓝色、有眼睛和光环的程序生成灵魂样式。每个客户端只绘制自己的自由灵魂，附身后隐藏；其他队友看不到灵魂模型、名字或地图上的灵魂位置。遗体仍正常可见、可救援、可搜索装备。
- 自由灵魂为全方向明亮视野，不再限制前方扇形、观察距离、楼层或烟雾遮罩；当前地图静态目标恢复显示，环境光调亮。附身后恢复被附身者正常视野与正常光照；复活、切图、退房也清理相应表现。
- 遗体和装备仍留在死亡点。灵魂飘远后，队友在遗体处救援或使用复活道具，会让身体在遗体处恢复，不能把活人复活到穿墙游览的位置。进入其他地图仍遵循现有队伍切图流程，灵魂不能开启门、拾取、交易或自行发起队伍切图。

## 接口与状态

| 位置 | 变更 |
| --- | --- |
| SoulRules / BaseModel | `free_soul`、`can_possess`、`detach`；玩家 `soul_speed`（2/4/6/8）、`soul_bounds`；`move` 意图允许自由灵魂，附身时不能移动；复活从遗体恢复位置 |
| Session | 新意图 `soul_speed(speed)`，整数白名单、真实 peer、会话 token/地图 revision/序号校验；不接收客户端最终位置 |
| Movement / LocalMovement | 自由漂浮分支不走身体碰撞；地图边界约束；客户端预测、确认和速度/生命周期改变时重置；活人/变异体规则保留 |
| PlayerPhysics | 提供本地图地面高度查询，漂浮时跟随地面高度，不移动遗体或碰撞身体 |
| VoiceRules | 灵魂语音只允许确认的附身双方，不沿灵魂声源位置向第三人转发 |
| SoulView / Vision / Map | 本地独有灵魂样式；隐藏远端灵魂与地图标记；自由灵魂全向视野、明亮环境及正常状态还原 |
| SoulPanel / 文本目录 | 距离过滤的附身按钮、四档速度按钮；中英两种文案完整显示 |
