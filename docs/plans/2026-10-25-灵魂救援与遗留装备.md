# 灵魂、救援与遗留装备

更新：2026-10-25。任务 SOUL-001，当前 AI 集成；用户明确要求将死亡后的灵魂、队友救援、附身语音和装备搜索接入当前基地/探索版本，覆盖旧版“救援/附身退出入口”的范围决定。状态：已实现，完成本地分层验证；Steam 双账号异地待验收。

## 行为

- 房主发现生命归零时立即进入灵魂状态。道具使用后立即检查，其他伤害来源在下一权威 tick 检查。治疗等待、换弹、翻滚、搜索和旧移动输入均清理；灵魂不能移动、射击、交易、使用道具或操作地图。
- 灵魂默认在遗体位置等待；可在右侧选择存活队友附身，共享其视角和视野，不控制身体。可主动解除，被附身者也有解除按钮。目标死亡、离线、地图切换或救起时清理附身。
- 存活队友靠近同层无遮挡遗体，按 F 开始 3 秒救援；离开原位超过 0.15 米、遮挡、失去目标、其他操作或主动取消会中断。完成后在遗体位置恢复 30 生命，无耗材要求。仍可救援正在附身的灵魂。
- 背包和四个装备槽的物品一次性转入遗体容器，基地仓库与营地币保留。按 E 顺序搜索，逐件或批量取走；支持每页 6 格翻页。武器 UID 和弹匣余弹一起转移；救起后不自动复制/返还已转移装备，剩余物品仍可搜索。
- 沿用当前自动拾音和静音设置。等待中的灵魂与活人语音隔离；附身后以被附身队友位置收发 20 米衰减语音，原说话者身份保留。仍需 Steam 登录、可用麦克风和联机。
- 交易商出售“剧毒胶囊（服用致死）”，售价 30 营地币，说明明确标记危险；使用扣除胶囊后生命归零。无需新美术依赖。
- 全员灵魂时可返回营地，以 30 生命恢复；存活队友带队回营地也恢复灵魂。遗留装备随原地图缓存在本次房间中，返回该地图可继续搜索。换地图解除附身和救援。退出整个会话后不持久保存遗体；人物存档保留死亡后的空背包/空装备，重进营地恢复 30 生命，不返还遗体物品。

## 最小接口与归属

| 位置 | 责任 |
| --- | --- |
| `features/rescue/soul_rules.gd` | BaseModel 调用的房主生命周期；`alive`、`observer_id`、`die`、`revive`、`command`、`tick`；不读 HUD |
| BaseModel 玩家 | `life`（alive/soul）、`possessing`（存活目标 peer ID 或 0）、`corpse_uid`、`rescue`（目标/遗体 UID/剩余时间/起点）；既有 hp 与库存继续归房主 |
| `state.corpses` + `state.containers` | 当前地图遗体的位置/归属与唯一库存；`world_cache` 按地图保留；未知物品沿用容器快照隐藏 |
| Session | `possess(target)`、`soul_wait`、`release_soul`、`rescue(target)`、`rescue_cancel`、`return_camp`；身份来自真实发送端，白名单、序号、限速、会话 token 与地图 revision 校验 |
| PlayerPhysics | 同层距离后补真实物理射线遮挡检查；纯规则测试使用矩形障碍回退 |
| `ui/soul_panel.gd` / Main / BaseView / Vision | 发出意图、遗体搜索与 F 入口、视角/视野跟随、隐藏失去行动的玩家模型；不确定最终生命或库存 |
| VoiceRules | 以确认的附身关系解析声源/听者位置，收发仍走原语音通道 |

Steam 协议升级为 `a1_bunker_v14`，不兼容 v13，队员必须使用相同构建。运行新增文件与 `.uid` 纳入依赖清单；不调整根工程、原有插件和外置素材。
