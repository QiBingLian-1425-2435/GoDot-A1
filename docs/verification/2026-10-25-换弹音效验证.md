# 换弹音效验证

更新：2026-10-25。

## 实现范围

- `base_view.gd` 观察每名玩家权威 `reloading` 状态，只在 `false -> true` 时调用一次 `reload` 音效，因此手动 R 与空弹匣自动换弹使用同一链路。
- 首次观察玩家时只记录当前状态，避免加入房间时对正在进行的旧换弹补播；玩家离开及切换世界时清理观察记录。
- `base_sound.gd` 将原有合成换弹声改成 260ms 的两段机械声，并将音量从通用效果音的 -23dB 提高到 -17dB。
- 该改动只消费同步状态，不修改弹药、计时或网络协议。

## 验证记录

在 Godot 4.5.2 下执行：

```text
python tools/run_base_tests.py --suite auto_reload
```

结果：headless `auto_reload_test`、可见窗口 `auto_reload_test_visible`、headless `ammo_supply_network_test` 共 3 次运行全部通过。覆盖自动换弹触发一次声音、重复状态不重放、中途加入不补播旧声音，以及既有弹药补给网络规则。

本轮未做 Steam 双账号双机异地听感验收；音效为本地表现，不改变联机数据格式。
