# 客机操作延迟修复与验证

日期：2026-10-19；任务 STEAM-INPUT-004。实现基线 `520ed67`，测试工具提交 `2191f22`。用户要求使用 GitHub Desktop 新建分支并合入本地 main，交付分支 `codex/client-input-latency-local-merge`；不包含远端推送。正式 Steam 双账号双机异地验收仍待执行。

## 原因与调整

上一轮解决了远端人物按快照跳动，但客机自己的角色仍等待输入上行、房主确认、下行快照和约 100 ms 插值。输入端与 Session 各有 50 ms 门限，局部动画速度还按指数衰减，普通步行降到 idle 门限约需 293 ms。房主没有网络往返，因此手感明显不同。

当前主代理协调 Main、Session 与协议，子代理只读评审；独立 worktree 提供真实延迟测试。实现职责如下：

- `base_input` 每物理帧采样；方向和姿态变化立即发送，保持输入仍按 20 Hz 发送。窗口失焦、背包/菜单/Steam Overlay 遮挡时送零输入。
- `movement_rules` 共享原有移动速度、姿态、体力和负重计算；房主仍唯一确认位置与玩法。`local_movement` 只预测本机移动和朝向，不修改 BaseModel、库存、伤害、存档或发送客户端最终位置。
- 房主回传已接受输入的序号、起始位置及体力/负重锚点。客机从对应本机发送时刻重算未确认移动，通过真实 CharacterBody3D 静态地图碰撞修正。输入新边缘拒绝旧方向 ACK，防止松键后恢复走路；历史限 2 秒，无推进 ACK 超过 1 秒终止预测。
- 本机角色/相机显示预测，腿部立即响应零速度；远端人物保留约 100 ms 确认快照插值。射击瞄准仍使用权威坐标基准。
- 小于等于 0.12 m 的静止显示偏差可暂时保留，避免物理采样相位差导致松键后再滑一步。逻辑位置立即校正，显示偏差在下次真实移动中按不超过实际步长的一半消除；较大校正继续收敛。新停止边缘可以终止已经收敛到小范围的校正尾巴；静止期间重复零输入不能冻结新的大校正。显示修正同样经过地图碰撞。
- 协议更新 `a1_bunker_v3`，轻量快照增加 5 个输入确认字段。双方须用同一新版本；根工程、地图和插件保持原样。

## 可复现证据

Windows / Godot `4.5.2.stable.official.6ce3de25a` / 固定 GodotSteam 4.23.1。源工程本机缺少已配置的 godot_ai 运行脚本，因此在 `artifacts` 忽略目录的测试副本中仅剔除缺失插件的配置；没有更改原项目配置。原生 Steam 扩展复制自已安装依赖。

`tools/run_latency_tests.py` 启动真实 Main 房主与客机，用标准库 UDP 代理延迟/丢弃完整 ENet 数据报，不替换 Session RPC 或物理。输入使用 Godot 物理按键事件；位置调整只用于准备测试场景。记录逐帧角色、权威坐标、动画、代理统计和源码散列。停止指标取观察窗口内最后一次移动，不能把第一帧停住后再次滑动漏掉。

| 测量 | 旧版稳定延迟 | 新版稳定延迟 | 旧版抖动丢包 | 新版抖动丢包 |
|---|---:|---:|---:|---:|
| 起步 | 545.2 ms | 32.6 ms | 359.3 ms | 32.3 ms |
| 松键后最后移动 | 558.3 ms | 0 ms | 479.4 ms | 0 ms |
| 松键到 idle 动画 | 868.5 ms | 31.8 ms | 698.6 ms | 32.3 ms |
| 反向响应 | 541.7 ms | 32.1 ms | 429.9 ms | 30.5 ms |

稳定配置每方向 200 ms；抖动配置每方向 120±40 ms、3% 丢包，seed 19。新版两组各客机 30、房主 3 项全部通过。0 ms 表示测试采样未再观察到位移，不表示网络零延迟。背包、暂停、模拟 Overlay 阻挡后两组均无后续滑移；真实墙体、较大房主校正、传送、远端连续性和玩法数据隔离通过。

基线证据 `artifacts/client_latency_baseline/{stable,jitter}`，新版 `artifacts/latency_qa_bb182139/{stable,jitter}`。早期候选 `latency_qa_6495c572` 和 `latency_qa_77193172` 发现延迟校正滑移，处理后才取得上述结果；未放宽延迟门限。丢失第一停止包的规则夹具允许有限权威纠偏，不能保证任何丢包情况下显示完全不校正。

## 分层验证与限制

- 静态：diff、模块/权威边界、UID 和运行白名单检查；子代理只读复查未发现可证实阻断项。
- Headless：fast 8 个入口通过，新增 local_movement 41 项，包含重复旧 ACK 断流保护、停止/反向、碰撞求解、状态隔离、历史清理和小纠偏。
- 同机多进程：原 network 5 个入口通过。原场景测试曾要求显示位置误差 <.015 m，改为逻辑预测仍须 <.015 m 且速度为零，显示另受 0.12 m 上限约束；专项逐帧测试继续约束静止后不得滑移。
- 导入：全新副本第一次导入在完成扫描后的引擎退出阶段发生 CrashHandlerException；保存原日志并同目录重试一次，重试返回 0 且无脚本/引擎错误，之后测试进程正常退出。工具仅对此特定退出故障有限重试，不掩盖解析错误。
- 可见界面、合并最新 main 后组合结果：以本轮交付补充记录为准。
- 真实窗口失焦、Steam 双账号双机异地：未执行；模拟 Overlay 仅验证阻挡输入代码，不能冒充 Steam Overlay 实际交互。
