# 病鬼模型与咳嗽接入

用户提供 GLB 替换程序初版。Blender 局部修整捂嘴手部凸点，保留纹理；双腿 thigh/shin 骨骼与渐变权重，保存 walk 动画。游戏按实际移动速度驱动骨骼，停止移动归零。

零号区入口首只怪物为病鬼，其他11只保留原近战鸭；总数量不变。12米视线发现、2米/秒靠近，2.8米内开始0.8秒前摇；咳嗽对3米三维范围内所有存活目标造成20伤害，墙体及烟雾阻挡，恢复2.2秒。伤害仅由房主决定。病鬼暂时免疫枪伤和击退，普通敌人仍可击杀。绿色云团与身体动作呈现咳嗽。
