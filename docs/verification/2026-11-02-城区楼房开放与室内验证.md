# 城区楼房开放与室内验证

日期：2026-11-02。基线 aee6cbd；分支 codex/city-enterable-buildings。状态：本地实现与自动化验证完成，Steam 双机异地待验。当前任务仅本地提交，不推送远端。

## 范围和接口

- 城区生成器中的全部 building、house 和三个院内棚屋改为可进入的一层，共 52 个独立入口。上层楼房保留外观，不增加楼梯、多层导航；工地开放框架仍可直接进入，瞭望塔、集装箱、帐篷不是此次楼房入口。
- 实心碰撞改成四周墙体、门楣和一层天花板；1.8 米宽门洞，地面使用统一平面物理，避免薄门槛导致进出卡住。L 形汽车旅馆的一处入口改到北面，避开另一翼楼体。
- 住宅放床、衣柜、沙发、台面；商店放货架、柜台、收银机；仓库放木箱、堆货；办公和公共建筑放桌椅。大空间补充多排陈设，保留中央十字通道。室内物品目前仅为陈设，不增加搜索、战利品或怪物。
- city_layout.json 升到 version 2，新增 buildings（稳定门 ID、矩形范围、门坐标、宽高、方向、用途）。city.gd 实现现有 interactions / can_reach_door / can_close_door / update_doors 接口，不修改 Main、Session、RPC 或权威规则。
- 复用已有 E 开门/关门文案及按键绑定。房主验证当前地图、距离、高度、遮挡和关门占位；状态复用 doors 快照与跨地图缓存。门碰撞同步转到铰链侧，保留物理遮挡。
- 进入楼房后，当前建筑上部和屋顶裁切显示一层；离开自动恢复。仅影响本机显示，墙体和天花板碰撞、视线阻挡不取消。
- 地图修订号由已有外置 manifest 接入 map_revision，双方需同一份新城区素材。没有新增运行文件，既有运行依赖白名单覆盖本次修改。
