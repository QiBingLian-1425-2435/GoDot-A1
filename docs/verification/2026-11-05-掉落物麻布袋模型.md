# 掉落物麻布袋模型

Blender制作棕色低多边形麻布袋，包含不规则鼓起袋身、粗布纹理、收口双绳、绳结及缝线；约0.6米宽、0.56米高，底部位于原点。所有地面掉落物沿原BaseView入口实例化麻布袋，按UID固定朝向。名称数量保留，稀有度通过名称颜色表达，不把袋子染成道具颜色。

原丢弃、权威拾取、位置高度、可见性及本地交互白描边接口保留。美术外置assets/props/loot_sack/，含loot_sack.glb、burlap_albedo.png、source/loot_sack.blend及asset_manifest.json；tools/build_loot_sack.py可重建。运行依赖清单已登记。

验证：Blender生成及Godot4.5.2导入成功；可见实景中实际丢弃三类物品，模型路径、贴地高度、E提示及描边检查通过；拾取后节点清理与数量一致通过。截图artifacts/loot_sack_game.png。未执行单独headless玩法套件、同机多进程及Steam双机异地验证。本次只改表现，协议不变，仅本地提交。
