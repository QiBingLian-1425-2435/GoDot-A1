## 发现与修复

1. 首轮 UI 接入时旧测试仍按字符串读取商品 metadata，现列表需要携带商品/出售组记录，导致测试报错；已更新调用并保留失败日志 material_ui_round1.log。
2. 第二轮数量测试发现 SpinBox 在值更新后无条件 apply 会读取尚未刷新的文本，数量退回旧值；改为仅文本编辑获焦时显式 apply，测试等待界面帧后验证实际库存变化。round2 有两条失败，round3/round4 及最终 headless/可见复验全部通过。
3. 最终检查发现原 Session 丢弃非整数购买 count 后会落入默认一件；改为保留非法数量为零，由房主拒绝。新增商人近处非法数量/旧地图包断言，最终三轮网络与全部相关套件通过。

失败轮日志保留在 artifacts/base_tests/material_*_round*.log，未用旧成功结果代替修复后复验。
