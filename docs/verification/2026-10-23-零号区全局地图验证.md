# 零号区全局地图验证

日期：2026-10-23。用户要求进入第一张探索地图后能查看全局地图和队友位置。

## 行为与边界

- 零号区地表按 `M` 打开全屏俯视地图，`M` 或 `Esc` 关闭；地图打开期间移动、瞄准和射击输入被阻止。
- 2026-10-25 优化交互：鼠标滚轮或 `+/-` 按钮在 100%–300% 间缩放，按住左键拖动地图，“定位自己”会放大并把本机标记移到视图中心；每次重新打开恢复完整地图视野。
- 2026-10-26 高清优化：底图改为 2×2 瓦片，总有效分辨率 4096×2304，并将投影视野收紧至零号区实际可玩区域；300% 放大仍使用接近原生分辨率的地图细节。双击可围绕鼠标位置放大，右键恢复完整视野。
- 2026-10-30 边界与性能优化：保持无形变的 16:9 投影，将世界纵向范围由 600 收紧至 525，减少四周无内容绿地；100% 固定使用轻量总览，放大后才显示高清瓦片。自由灵魂的全图可见节点与材质切换只在进入/离开该状态或切图时执行，不再每帧重复遍历整张零号区；人物、掉落物及交互状态仍按帧更新。
- 金色标记为本机，青色标记为同一房间队友，并显示成员名。标记只读取现有房主权威移动快照中的 `players[*].pos`，不新增 RPC、不修改共享状态或协议版本。
- 玩家点与名字位于独立覆盖层，不随底图放大，缩放后仍保持可读尺寸；100% 全图先加载同投影的 `map_overview.png`，首次放大时才加载四张高清瓦片，缺少瓦片时保持低清底图可用。
- 地图底图由已还原的零号区素材通过 `python tools/generate_global_map.py` 生成到外置素材目录，并登记进 `asset_manifest.json`，随现有地图素材一起校验和打包；图片继续不进入 Git。
- 当前只开放零号区地表全局地图。基地不显示；神秘山洞按 `M` 会提示当前范围，避免拿地表底图错误表示洞穴。
