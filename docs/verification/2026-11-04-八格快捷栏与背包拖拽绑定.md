# 八格快捷栏与背包拖拽绑定

HUD与背包右下均显示8格，默认按键1到8；沿用原1步枪、2手枪、4医疗包、5水，其余默认空槽。可在原快捷键设置修改按键，原动作ID保留以兼容已有按键配置。

从随身背包拖入武器、装备或可使用道具即可绑定，材料/贵重物及仓库物品不接受。绑定按物品种类，不移动或复制物品，整理/换堆后自动寻找当前随身物品；已装备武器/护甲保持当前装备。右键清空绑定，绑定保存在本机user://quick_slots.cfg，与他人独立。物品耗尽显示空格，保留绑定以便补充后自动恢复。

按键沿用原equip/use房主指令，UI只维护本地快捷偏好，不改变共享背包或网络协议。背包拖拽回调核验最新槽位UID，拒绝已过期拖拽。
