# 联机弹道与弱网预测修复

状态：本地实现及自动验证完成；Steam 双账号双机异地待验。分支 codex/network-shot-jitter，开工同步 origin/main=d989f12。保留开工前无关未跟踪 tests/base/infinite_stamina_test.gd.uid。

## 原因与处理

1. 弹道依赖 state.shots，寿命只有 160ms。其显示使用房主剩余 TTL 加客机快照年龄；靠近墙体时显示窗口更短。不同可靠通道上的完整快照还可能超越射击快照，旧序号整包被丢弃，短暂射击事件随之消失。
2. Session 在已校验房间 token 后提取确认射击到本地表现队列；同地图被超越的旧快照也只提取未见事件，不覆盖共享状态。按人物和射击序号去重，最多64条，首次收到起计时160ms，重复包不延长；切图、离房清理，旧房间/旧地图拒绝。弹道和命中位置仍由房主确定，未预测伤害或弹药。RPC签名与协议 v18 不变。
3. 饱食度低于50后，负重上限不断变化；原 local_movement.confirm 每次变化都 clear，丢失未确认输入和重演历史、回跳至迟到权威位置。已改为更新权威属性、保留预测时间线，耐力上限下降仍钳制。传送、离房及断流上限继续有效。
4. 当前修复未改远端插值和断流保护，不承诺严重断网时持续走动，也不承诺消灭全部合法纠偏。
