# ENEMY-024：零号区近战狂化鸭

日期：2026-10-24；分支 `codex/hostile-ducks`，基线 `1eddc57`。当前 AI 统一修改 Main 接线、世界流转和 Session 协议，不存在同目录并行写入。已实现，本机验收通过；正式 Steam 双机异地待测。

## 玩家体验与参数

首次进入本房间的零号区地表，在入口附近 14、22、30 米候选环上选择最多 4 个有支撑、无胶囊重叠且至少有两个可走出口的位置，怪物间距至少 7 米。当前地图实测生成 4 只；地下基地和洞穴不新增怪物。怪物为程序生成的绿灰色狂化鸭，有红眼、利爪、奔跑摆动、攻击蓄力/挥爪和侧倒动作，不依赖新美术包。

- 100 生命，12 米发现距离，前方 140 度视角；2 米内能察觉身后玩家。
- 看见玩家后以 4.6 米/秒追赶；比步行快，比奔跑慢。使用人物同源的空间胶囊扫掠及低台阶处理；受阻时尝试左右侧向移动，不穿墙。
- 墙体、关闭的门、明显楼层差和烟雾阻挡发现；丢失视线后追向最后看到的位置最多 2 秒，然后返回出生点。当前是短程追击和局部绕障，没有全地图导航网格或复杂迷宫寻路。
- 1.35 米内开始蓄力 0.45 秒，再挥爪造成 18 点伤害，恢复 0.85 秒后才能继续。实际命中重新检查距离、高度与遮挡，玩家离开范围或躲到掩体后可避开。
- 现有枪械射线能命中怪物，弹药、射速、世界遮挡沿用原规则；跨楼层不能仅按二维位置命中。步枪正常 3 发击倒。击倒后不再移动或伤害玩家；切图往返保留本房间击倒状态，重建房间重新生成，不声称怪物状态跨房间落盘。
- 玩家生命归零后暂时倒地，停止移动、开火和物品操作；5 秒后回到本区域进入点，恢复 50 生命，并有 3 秒敌人攻击保护。背包保留。这是首版战斗恢复流程，不新增死亡掉落、救援或战利品系统。

## 模块、接口和权威

| 模块 | 职责 |
| --- | --- |
| `features/enemies/enemy_rules.gd` | 纯共享规则：发现、目标、追击记忆、蓄力、伤害、死亡、玩家倒地与恢复；只由房主/单人 BaseModel.tick 调用 |
| `features/enemies/enemy_director.gd` | 物理适配及生命周期：真实地图射线、胶囊移动、安全出生位置、地图切换清理；以 enemy_sight / enemy_move 回调接入规则 |
| `features/enemies/enemy_view.gd` | 本地程序模型、血量名牌、奔跑/挥爪/倒地动画与位置平滑，不决定命中 |
| `combat_system` | 射击候选加入敌人，沿原射线遮挡判定伤害 |
| `world_travel / world_flow` | 敌人地图缓存、区域返回点与立即清理旧表现 |
| `Session` | 可靠快照初始化状态，20 Hz 小包同步敌人位置/生命/动作；客户端不模拟 AI 或扣血 |

新增 state.enemies、enemies_seeded，以及玩家 knockout_remaining、enemy_immunity、enemy_return。敌人状态写入者为房主。新 `_enemy_snapshot` RPC 仅接受房主，校验会话令牌、序号、地图修订；迟到的可靠快照不会覆盖更新的敌人状态，旧地图或乱序包不能复活怪物。四只敌人的紧凑运动消息小于 1200 字节；保留原五人移动消息格式。

Steam 协议升级为 **a1_bunker_v12**，开发 build 标识同步更新。所有成员必须使用相同新构建。敌人视觉遵循现有本地视野，退出/切图立即清空物理适配节点与表现。纯背包模块不依赖怪物或地图；饱食度负重联动保留。

三个运行脚本及 UID 已加入运行依赖清单，无新增外置素材或插件。根项目仍是唯一资源根，保留 godot_ai。

## 实际验证

引擎 Godot 4.5.2。QA 源码副本位于 `artifacts/ground_zero_qa`，素材沿用本机还原内容；只在 QA 排除缺失的开发 autoload，根配置不改。

- 静态：Godot 导入/解析、差异空白、运行依赖路径及提交范围检查。
- Headless 规则：25 项通过，包括视角/遮挡/烟雾、追击、前摇与闪避、攻击冷却、倒地/返回、真实枪械规则、不同楼层、加载暂停、旧包拒绝及四怪消息预算。
- 真实零号区：13 项通过，包括 4 个安全出生点、实体追击胶囊无重叠、真实遮挡阻止爪击和枪击、命中与死亡、返回基地清理、再进地图不刷新死亡状态。
- 可见场景：真实地图 14 项通过；已检查 `enemy_encounter.png`，另用 `enemy_visual_test.gd` 查看奔跑/蓄力/倒地并列截图 `enemy_visual_preview.png`。修正名牌朝向与倒地陷地问题；切图偶发一帧残留通过 WorldFlow 立即清理修正。
- 同机多进程：真实 ENet 房主/客机验证追击运动、玩家受伤、客机开枪由房主计算伤害、3 发消耗及死亡同步；另完成原网络套件 6 次回归，包括五人和房主断开。
- 回归：快速套件 11 次、探索 3 次、翻滚 3 次、饱食度 3 次通过。新增实体遮挡夹具首次体积不足以同时覆盖眼睛视线与水平弹道，改为覆盖二者的立柱后补验通过。
- Steam 双账号双机异地及多人真人难度体验：未执行；不以 ENet 替代。

复验命令：`python tools/run_base_tests.py --suite enemies --godot "实际 Godot 路径"`。专项日志和截图位于 QA 的 `artifacts/base_tests/`、`artifacts/`。本轮仅本地提交，不合并 main、不推送远端。打包和包内复验另记。
