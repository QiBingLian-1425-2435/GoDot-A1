# 探险家男主贴图接入

用户提供探险家GLB白模，Blender创建配色纹理图集：灰绿夹克、卡其裤、棕色背包鞋靴、深棕发色与琥珀挂件。UV按部件及局部区域分配。男主接入新模型，女主继续原资源；沿用现有骨骼附件，裤腿按左右拆分。

外置素材 assets/characters/explorer/：male.glb、explorer_albedo.png、source/explorer.blend、asset_manifest.json。重建命令：Blender --background --python tools/texture_explorer.py -- 输入.glb。脚本与依赖登记提交Git，素材不上传。

Godot 4.5.2导入成功，零号区可见回归17项通过，独立角色近景截图 artifacts/explorer_game_closeup.png。此轮为参考配色初版，不是逐像素复刻；男主纹理固定颜色，原换色设置暂不影响此材质。未验证全套动作穿插、同机多进程或Steam异地。
