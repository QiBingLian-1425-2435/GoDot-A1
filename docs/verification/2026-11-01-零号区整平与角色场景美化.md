# 零号区整平与角色、场景美化

日期：2026-11-01 · 状态：已实现，已做本地 headless/可见画面验证，未做联机验证。

## 改动

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 地形整平 | `worlds/ground_zero/terrain_flatten.gd`（新） | 零号区地表高于地面基准（-0.0064 m）的山丘全部压平；湖、河等低洼水域保留。运行时处理，不改外置素材。 |
| 物件落地 | 同上 + `ground_zero.gd`、`map_library.gd`、`walkability_repairs.gd` | 渲染件、碰撞体、门、灯、实体、传送目标、地标、出生点都按原地形高度同步下移；门的开/关姿态同步移动；山坡树根补洞在整平后不再生成。 |
| 联机一致 | `features/exploration/world_flow.gd` | `map_revision` 追加 `+flat1`，新旧构建不会进同一房间（物理地形不同）。 |
| 场景风格 | `worlds/ground_zero/surface_look.gd`（新）、`terrain.gdshader` | 参考 POLYGON 低多边形风：暖色主光 + 偏冷环境光、Filmic 色调、饱和度/对比度提升；地表草地/泥地/路面分层着色、路径边缘更清晰、大尺度色块变化。只作用于地表，回基地/洞穴时恢复原设置。 |
| 角色模型 | `tools/build_human_models.py`（新）→ `assets/characters/humans/*.glb` | 按 A/C 重建男女身体：圆润夹克（A：敞开领口、深色内搭、立领、胸袋；C：衬衫领、门襟纽扣、下摆）、带袖口的袖子、带拇指的手、裤脚卷边、带鞋底的圆头靴，眼睛高光与腮红。保留原头型与头发（不改动 `refine_human_hair.py` 产出的发型）。 |
| 背包 | `features/geometry/geometry.gd`、`features/player/base_actor.gd` | 新增 `G.rounded_box`，背包改为圆角帆布包造型。 |
| 预览 | `worlds/ground_zero/map_preview.gd` | 预览使用新光照；`--legacy-look` 可看旧光照。 |

角色颜色仍由更改形象面板的 hair/skin/shirt/pants 控制；绑定骨骼和节点命名（`<Bone>__<part>`）不变，动画沿用原 rig。

## 重新生成角色模型

在项目根执行：`python tools/build_human_models.py`（仅需 Python 3 标准库，无需 Blender）。脚本读取现有 GLB 中的头发网格并保留，其余部分重新生成，同时更新 `asset_manifest.json`。如需重做发型，先跑 Blender 的 `refine_human_hair.py`，再跑本脚本。

注意：`assets/characters/humans/source/*.blend` 仍是旧身体，未同步本次改动。

## 验证记录

- 已验：Godot 4.5.2 headless 导入与主场景启动无脚本错误。
- 已验（可见画面，Linux 软件渲染）：单机进入零号区，出生点 StartPoint_1 原高 4.23 m，整平后玩家站立高度 0.03 m；地表新光照生效；回基地后基地光照与改动前一致；男女角色正/背面、背包与步枪姿态截图检查。
- 未验：Windows 实机画面、性能对比、同机多进程与 Steam 双机异地联机、`run_base_tests.py` 全套测试。
- 已知：全局地图底图 `map_overview*.png` 仍是整平前烘焙的图（山体阴影），需要时用 `tools/generate_global_map.py` 重新生成。

## 补充：视野阴影与物品显隐（2026-11-01）

- `features/visibility/vision_fog.gdshaderinc`：零号区内，本机玩家视野外（视锥外、被墙/树/石头挡住、超出视距）的地面和物件会变暗、偏冷、略降饱和，视野边缘、树墙后的遮挡阴影都做了宽幅柔和过渡（多点采样半影，可调 `vision_edge_soft`、`vision_cone_soft_deg`）；基地或灵魂自由视角时不生效。阴影强度和色调可调 `vision_shadow_strength`、`vision_shadow_tint`。
- `features/visibility/exploration_vision.gd`：可搜索的容器（箱子、柜子、马桶等）不再因看不见而隐藏，只会被阴影压暗；地上掉落的物品（枪等）、其他玩家和敌人仍然只在视野内显示。视锥边缘过渡只往视野内收，不会多露出实际看不到的范围。
- 只改本地画面，玩家能否看到、能否互动的判定没变，不影响联机同步。
- 已验：单机进零号区两个出生点截图，阴影与容器显示正常，无脚本/着色器报错。未验：Windows 实机、联机。
- 视野内黑色细线修复：画面用的视线射线先做形态学闭运算（`exploration_vision.gd` 的 `THIN_RAYS`），树干、柱子、小杂物这类窄于约 7° 的遮挡不再在亮区投出放射状黑线；墙、石堆、房屋仍有遮挡阴影。只影响画面，敌人/物品是否可见仍用真实射线判定。
