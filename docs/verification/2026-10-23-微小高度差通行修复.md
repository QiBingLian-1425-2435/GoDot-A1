# 微小高度差通行修复

日期：2026-10-23。

## 问题与原因

人物移动器已有最大 0.46 米的自动抬脚，但前向支撑只在固定 0.38 米处采样一次。宽平台和长坡面可以命中；窄门槛、短踏步或斜向接近时，顶面可能落在采样点之间，胶囊会先撞上立面而停止。

下降方向还有一处非对称问题：下一采样点位于碰撞三角形或短台阶接缝时，脚下射线可能暂时漏掉可见地面并命中更深的底面。原代码直接拒绝该轴移动，下一帧又从同一点重试，形成能上不能下的固定“空气墙”。

## 改动

- `features/player/player.gd`：在胶囊前向可达范围内分段采样支撑面，选择不超过原有最大抬脚高度的最高合法顶面。
- 保留原有坡面平面比较、头顶净空检查、胶囊清空检查和相对脚下地面的高度限制；连续坡面不会因多点采样被当成台阶。
- 下降时若直接支撑缺失或落差异常，改为寻找前方 0.38 米内的合法落脚面并允许水平跨越窄接缝；人物只有在脚下出现直接且落差不超过 0.46 米的支撑后才降低高度，不跨越悬崖或吸附到深层碰撞。
- `tests/base/step_up_test.gd`：新增 0.12 米宽、0.16 米高的门槛及门框，覆盖正向和斜向通行，并检查通行后胶囊无重叠。
- `tests/base/spatial_movement_test.gd`：新增上下层之间存在窄接缝的下降复现。修复前稳定停在接缝，修复后通过且胶囊无重叠。
- `features/player/base_input.gd`：脚步声改用碰撞求解后的实际速度，而不是按键输入方向；客机读取本机预测速度，房主读取权威速度。顶住墙角保持静音，实际沿墙滑动仍有脚步声。
- `tests/base/duckov_animation_model_test.gd`：增加顶墙静音与沿墙移动发声状态断言。
