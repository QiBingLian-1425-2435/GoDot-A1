# 枪械命中击退

状态：实现及本地验证完成。分支codex/gun-hit-knockback，起始5c89b0b，仅本地提交，不合main或推送。用户进一步明确怪物及被友伤命中的队友均击退，已扩展；固定靶、墙体不产生位移。

## 行为与接入

- 房主确认枪械射线击中存活怪物后，沿弹道施加5.5米/秒初速度，22米/秒²减速，持续0.25秒；平地无阻挡总位移约0.6875米。
- 击退中断怪物蓄力，暂时停止追击与攻击；结束后恢复AI。连续中弹替换冲量而非无上限叠加；致命命中维持现有倒地，不滑动尸体。
- BaseModel增加enemy_push物理回调，EnemyDirector使用原有胶囊move_spatial处理墙、门、地面和台阶，不使用追击的主动绕障逻辑。
- EnemyRules维护房主临时knockback速度与stagger模式。既有敌人运动包已含位置、速度、模式、计时，客机仅展示确认结果。队友扩展升级协议至v21，开发build_id为a1_knockback_dev_20261028，联机双方更新同一构建。
- EnemyView根据受击速度倾斜身体，击退中停跑步动画；结束平滑回正。无新增玩家可见文案、外置资源或运行依赖文件。

## 队友友伤击退扩展

- 非致命友伤沿同一弹道施加5.5米/秒初速、22米/秒²减速，击退期间暂时抑制自主横向移动；已有空中跳跃继续重力起落，同时接受水平冲量。致命伤仍进入灵魂/遗体流程，基地仍无友伤。
- Movement规则和真实人物碰撞求解器推进位移。切图、死亡和复活使用原reset_transients清除残留冲量，不写入持久背包/人物档。
- 受击序号与剩余冲量进入20Hz运动包。客机收到受击确认后舍弃命中前输入锚点和重放历史，按确认位置继续衰减；恢复普通预测前先收到房主结束确认。松键不取消受击位置校正，修复专项发现的6厘米残留偏差。
- 速度量化为0.05米/秒，双分量各一字节；受击序号为16位循环计数，乱序保护仍由外层运动包序号负责。两个耗尽标志合并进已有位标志，五人包1120字节，保持原1200字节门槛。
