## 版本与交付方法

修复后执行 rebase origin/main，已是最新基线，无冲突。源码复审对象为 36fd5ec；后续仅增加本审核记录、任务授权说明和更正旧运行说明的 Steam 状态。合并前再次检查 head/base 与最终差异。

命令行 push dry-run 因无 HTTPS 密码/令牌且终端提示被禁用而失败，不读取或索取密码。使用已连接 GitHub 的 tree/commit/ref 接口提交同一完整文本树，以远端当前 main 为父，expected_sha 限定且 force=false。接口生成提交元数据，远端 SHA 与本地原任务提交不同；通过树 SHA 相等核对内容。原任务分支保留审核链和本地提交，不丢弃历史。推送后 fetch 并快进本地 main，最终远端 SHA 以实际工具回执为准。
