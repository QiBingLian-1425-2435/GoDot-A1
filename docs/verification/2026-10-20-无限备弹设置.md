# 无限备弹设置

2026-10-20；分支 `codex/infinite-reserve-ammo`，基线 `47a78d7`。本次未合并 main、未推送。

主菜单或游戏内 Esc → 设置 → 弹药规则 → 无限备弹。默认关闭，仅当前程序运行期间保留，不写角色存档。单人或房主可修改，房间内全队生效。客机开关禁用，房主也拒绝非 1 号玩家修改；客机离房清除继承选项。

开启后空背包可换弹，不消耗或生成背包弹药，仍需 R 和 1.6 秒装填，射击仍扣弹匣，容量不变，HUD 显示 ∞。关闭恢复库存消耗。换弹完成时采用当前规则。UI → Session 可靠动作及负载过滤 → BaseModel 权威校验，完整快照同步，中途加入接收当前值。双方使用同一构建；无新增运行依赖。
