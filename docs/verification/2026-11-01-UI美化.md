# 全局 UI 美化

日期：2026-11-01 · 状态：已实现，已做本地可见画面验证（Linux 软件渲染 1600×900），未做 Windows 实机与联机验证。

## 改动

| 模块 | 文件 | 说明 |
| --- | --- | --- |
| 统一视觉 | `ui/widgets/ui_theme.gd`（新） | 统一调色板（暖白文字、金/琥珀强调、深石板底色、青绿辅助）与样式构建：面板（顶边强调 + 投影）、HUD 半透明卡片、按钮（绿色为实心主按钮，其余为深色描边按钮）。`build()` 生成根 Theme，覆盖 Button、OptionButton、LineEdit、CheckButton（程序生成开关图标）、HSlider（琥珀进度 + 圆钮）、滚动条、ItemList、PopupMenu、Tooltip、ProgressBar、Panel。 |
| 状态条 | `ui/widgets/stat_bar.gd`（新） | 生命/耐力/饱食/水分/SAN 改为圆角细条（轨道 + 填充 + 高光，低于 25% 偏红），修复旧 ProgressBar 显示成粗色块的问题。 |
| 加载 | `ui/widgets/loading_dots.gd`（新） | 加载界面三点脉冲动画。 |
| HUD | `ui/base_hud.gd` | 区域卡片（琥珀竖条 + 粗体地名）、生命体征卡片、快捷栏托盘与金色键位角标、弹药卡片（大号粗体弹数）、操作提示胶囊条、互动提示胶囊；提示消息改为随文字宽度伸缩的胶囊，并下移避开语音状态行；暂停菜单、通用对话框标题栏（琥珀竖条 + 细分隔线 + 圆形关闭按钮）；加载界面卡片。所有 `_button/_panel/_style/_progress` 辅助函数改走 UiTheme，其余面板自动套用。 |
| 物品格 | `ui/widgets/item_slot.gd` | 深色圆角格子、稀有度底部辉光 + 描边、左上角稀有度字标、数量胶囊、选中金色描边、悬停提亮。 |
| 全局地图 | `ui/map/global_map.gd` | 面板与按钮改用 UiTheme，金色粗体标题，地图区内嵌深色边框。 |
| Steam 面板 | `ui/network/steam_panel.gd` | 状态框、好友房间列表改为深色内嵌框，不再是高亮青色块。 |
| 灵魂面板 | `ui/soul_panel.gd` | 边框改为统一的浅描边色。 |

只改画面，不改任何游戏逻辑、存档或联机同步；无新增文本键。

- 已验：Godot 4.5.2 导入与 headless 主场景启动无脚本错误；`check_game_texts.py` 0 错误（已 `--write-sources`）。
- 已验（截图逐屏检查）：按任意键界面、主菜单、设置、操作指南、IP 直连、Steam 联机、基地 HUD、背包、暂停菜单、更改形象、快捷键配置、商人购买、工作台制作、营地升级、加载界面、全局地图、提示消息；零号区与废弃城区单机进入 HUD 正常。
- 未验：容器搜索面板、灵魂面板实际画面（只改了边框色，未截图）；Windows 实机字体（微软雅黑）下的排版；4K/非 16:9 分辨率；联机。
