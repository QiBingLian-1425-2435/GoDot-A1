# 病鬼模型初版

Blender 5.2.2 制作低多边形静态病鬼，源文件位于 assets/characters/sick_ghost/source/sick_ghost.blend，GLB 同级上层。运行 tools/build_sick_ghost.py 可重建，素材外置不提交。

现有 enemy_view 统一替换外观，保留原名称、近战规则与状态接口。尚未实现独立病鬼类型、骨骼行走、咳嗽技能；当前是美术初版。
