## 本地提交检查

`tools/check_git_files.py` 检查索引中实际 blob 大小，并拒绝用 git add -f 强制加入的忽略文件。本机 `.git/hooks/pre-commit` 已调用该脚本；只使用本机已配置 Git 身份，不修改全局身份配置。

在独立临时 Git 仓库实际测试：小文本通过；强制加入忽略目录的素材被拒绝；恰好10 MiB的blob被拒绝。测试文件没有进入项目仓库。

复验：

```powershell
python tools/check_git_files.py
git check-ignore -v assets/characters/hero.png .references_code/123.rar .godot/uid_cache.bin artifacts/demo.png addons/godot_ai/plugin.cfg
git status --short
git remote -v
```

Git hooks 不随 clone 自动安装，成员可手动执行上述 Python 检查，或在项目根 PowerShell 安装同样的本地 hook（需 Python）：

```powershell
$hookPath = Join-Path (git rev-parse --git-dir) 'hooks/pre-commit'
[IO.File]::WriteAllText($hookPath, "#!/bin/sh`nexec python tools/check_git_files.py`n", [Text.UTF8Encoding]::new($false))
```

Hooks 可被人为绕过，`.gitignore` 也不是安全权限边界；本轮实际待提交内容已经检查，后续每次提交/推送仍须检查内容及新增历史。没有宣称可以靠忽略规则拦截所有未知文件或凭据。
