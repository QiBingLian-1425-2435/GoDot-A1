## 玩法入口

- 基地出口旁新增「城区出口 · 前往废弃城区」（地面标 CITY ROUTE），全队一起进入。
- 出生点：南侧主干道中段 (140, 0, -12)。
- 撤离点：东北角路口 (268, 0, -268)，地面黄圈 + 锥桶 + 旗杆 + 白色面包车，互动「撤离点 · 返回地下基地（全队）」。
- 可活动范围约 280 m × 280 m，四周空气墙（只挡人），墙外是一圈松树林，再外面一圈石山。

## 实现

| 文件 | 说明 |
| --- | --- |
| `tools/build_city_map.py` | 地图生成器（纯 Python 标准库，固定随机种子）。输出低多边形、平面着色、顶点色的 `assets/worlds/city/city.glb`（按 64 m 分块），以及碰撞/出生/撤离/边界数据 `city_layout.json` 和 `asset_manifest.json`。改布局就改这个脚本后重跑：`python tools/build_city_map.py`。glb 也能直接用 Blender 5.2 打开查看或手改。 |
| `worlds/city/city.gd` | 地图节点：加载 glb、按类型批量建碰撞盒（建筑/车辆遮挡视线，矮障碍只挡人和子弹，空气墙只挡人）、地面碰撞、撤离点。实现与零号区相同的世界接口（视野阴影、镜头遮挡镂空等）。 |
| `worlds/city/city_surface.gdshader` | 顶点色材质 + 视野阴影 + 镜头与角色之间的高楼镂空（3.4 m 以上才镂空，车辆不受影响）。 |
| `worlds/city/city_preview.tscn` | 开发预览：`--capture=out.png --point=x,y,z --size=40 [--overview]`。 |
| `features/exploration/world_flow.gd`、`world_travel.gd`、`worlds/bunker/bunker.gd`、`ui/base_hud.gd` | 接入新区域 `city`：加载、光照（沿用地表风格）、活动边界、基地出口、HUD 名称。 |
| 本地化 | 新键 `city.name`、`city.extraction`、`bunker.city_exit`、`bunker.city_route`、`base_hud.city`（中英同步）。 |

联机：城区素材版本号并入 `map_revision`，房主与客户端城区素材不一致时不能同房。导出预设已加入 `assets/worlds/city/*.json`；`city.glb` 作为导入资源随包导出。

## 验证记录

- 已验（Linux 软件渲染，单机）：从基地城区出口进入，出生落地高度 0.04 m；四个方向贴墙行走分别停在 x=-2.65、x=282.6、z=+2.65，空气墙生效；向北沿中轴走会被路口路障挡住（设计如此，可绕行）；撤离点返回基地成功；零号区进出未受影响；文本审计 0 错误。
- 规模：约 19 万三角面、474 个碰撞盒；软件渲染下单帧约 480 次绘制调用。
- 未验：Windows 实机帧率、Steam 联机、`run_base_tests.py` 全套测试。
- 尚未做：可搜索容器、怪物、全局地图（按 M 在城区会提示仅限零号区）。
