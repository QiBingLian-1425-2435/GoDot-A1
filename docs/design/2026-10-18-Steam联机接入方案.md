# Steam 联机接入方案

更新：2026-10-18。用户确认使用测试 App ID 480。开发接入已实现，本机真实账号与导出包房主验证通过；双账号双机不同网络的加入、传输及完整对局尚未执行，不标正式验收完成。

## 固定依赖与恢复

Godot 4.5.2 stable Windows x64，GodotSteam GDExtension 4.23.1（Godot 4.4+ / Steamworks 1.65），已包含原生 SteamMultiplayerPeer，无需安装旧版第三方 peer 或更换自编译编辑器。[精确下载、SHA-256 与文件清单](../dependencies/2026-10-18-steam_runtime.json)随源码交接。`python tools/setup_steam.py` 恢复到忽略的 addons/godotsteam，只提取固定扩展、Windows DLL 与许可证；不启用依赖自带的编辑器更新插件，保留原有 godot_ai。

app/network/steam_config.cfg 保存开发 App ID 与版本；打包阶段改成提交和实际运行源文件散列组成的构建号，不改源配置，不同包拒绝混连。

## 玩家流程与职责

默认 Steam：创建最多五人的好友大厅，通过 Overlay 邀请或复制房间号加入。所有成员打开 Steam、使用不同账号、互加好友并使用同一个完整解压包。480 只作开发测试，不发布公共 Spacewar 大厅列表。邀请界面已接线，实际接受需第二账号测试。

SteamLobby 推进 SDK 回调、管理大厅/邀请/超时/清理，输出真实 native peer；Session 安装 peer 并沿用既有 RPC 与房主权威。原生 create_host/create_client 构成星形连接，房主 ID 为 1，禁用客户端之间中继。房主验证实际 Steam ID 属于当前大厅后才加入权威玩家表。大厅不是最终游戏状态。

加入比较 game、protocol、build、owner、phase；拒绝其他 Spacewar 应用、不同包、已开局或更换房主的大厅。开局和结算锁加入，返回准备后开放。原房主离开/Steam 离线即结束，不跟随 Steam 自动转移大厅所有权。取消后忽略晚到回调并退出误创建/误加入的大厅。

实际 SteamMultiplayerPeer 承担数据传输；调用 initRelayNetworkAccess 不代表已验证某连接使用中继。目标无需公网 IP 或端口映射，真实异地路径与可用性待成员验收。房主必须持续运行，个人撤离不停止服务；不做房主迁移、掉线续局、独立服务器或游戏内语音。ENet/LAN 保留为显式开发入口，不能替代 Steam 验收。

## 分发与验收

`python tools/build_steam.py --godot <4.5.2_console.exe>` 生成完整 Windows x64 ZIP：运行时、PCK、固定扩展、外置素材、480 标识、启动器、许可证和散列清单。输出与临时工程忽略 Git；仅临时工程禁用 godot_ai，不改源插件或建立第二个正式工程。

DLL、素材、SDK、ZIP 不入 Git，不用 LFS；提交源码、预设、依赖清单和恢复工具。包通过团队共享盘/文件传输分发。执行[验证与分发步骤](../verification/2026-10-18-Steam联机验证与分发.md)：双账号双机异地一局，再五人连续三局。
