# Steam 联机接入方案

更新：2026-10-19。当前已接入地下基地 Demo，保留 Godot 4.5.2 / GodotSteam 4.23.1（包含 SteamMultiplayerPeer）/ Steamworks 1.65 / App ID 480。固定下载与 SHA-256 见 docs/dependencies/2026-10-18-steam_runtime.json。Python setup_steam 只恢复一次 Windows 扩展，也可共享 addons/godotsteam 后重启编辑器；无需虚拟环境，F5 正常运行。DLL 不进 Git。

当前 app/network/steam_service.gd 管理 SDK 回调、大厅、好友房间发现、邀请/复制、Overlay、版本和原房主验证，输出真实 peer 给 Session；Session 是唯一玩法权威。保留邀请和房间号加入，最多五人，基地允许中途加入。大厅校验 game=a1_bunker_base、protocol=a1_bunker_v2、精确 build、成员数与原房主；旧 v1、旧旅店和队长参考原包不兼容。SDK 请求超时/取消后清理晚回调，不把其他 Spacewar 大厅当成本项目。

2026-10-19 移动卡顿修复：移动意图/20 Hz 轻量状态使用真正 unreliable + seq/token；可靠完整状态保留动作即时和 2 Hz 周期刷新。客户端确认样本经 100 ms 缓冲逐帧显示，相机跟随同一展示坐标。未改变房主权威与物理；旧 v1 成员必须一起更新。[原因、通道兼容与分层验证](../verification/2026-10-19-Steam人物移动卡顿修复.md)。

原生 create_host/create_client 构成房主星形传输，客户端互相转发关闭；调用中继初始化不等于某条实际连接已证明走中继。SDK/dynamic peer 真的加载后才报告可用，没有把 ENet 成功当作 Steam。房主离开结束会话，不迁移权威、不掉线续局。Steam 无法初始化时明确提示，仍可单人/IP 开发验证。

F5 运行使用 steam_config.cfg 开发构建号，成员须同分支同提交；Windows 包按当前运行白名单与实际内容生成构建号。打包工具排除旧素材、参考项目和 godot_ai（源工程不改插件），生成独立 EXE/PCK/DLL/480 标识/许可证/散列清单，放在忽略的 build。源工程和成员包分别验证。

本轮真实 Steam 房主/复制/五人限制/元数据/离房 10 项已验证；双账号双机异地客户端、真实好友邀请接受和五人 Steam 尚待验收。具体证据见[基地迁移验证](../verification/2026-10-19-地下基地迁移验证.md)，历史旅店证据仅对应历史实现。正式方向仍按项目共识执行。

官方依赖来源保持 [GodotSteam 4.23.1](https://codeberg.org/godotsteam/godotsteam/releases/tag/v4.23.1) 与 [Steam 大厅文档](https://partner.steamgames.com/doc/features/multiplayer/matchmaking)，未另引第三方传输插件。
