# 项目结构说明

更新：2026-10-18。队长初稿按现有 app/features/worlds/ui 骨架迁入，根目录是唯一正式运行资源根。

```text
project.godot                       Godot 4.5.2，入口 app/main.tscn
app/
  main.gd / main.tscn               组合模块、输入映射、界面意图接线
  network/session.gd               ENet、RPC 验证、状态快照、连接生命周期
features/
  match/match_model.gd             权威本局状态、命令路由、固定步推进和生命周期
  inventory/                      纯背包规则、物品定义、归属转移、地面物表现
  player/                         CharacterBody3D 主体、物理适配、纸片表现
  enemies/monster_system.gd        巡逻/追逐/搜索、命中事件与冷却
  rescue/rescue_system.gd          持续救援、倒地/死亡、尸体生成
  extraction/extraction_system.gd  个人撤离、一次入账、全队结算
  companions/companion_system.gd   AI 跟随、搜集、救援、撤离意图
  possession/possession_system.gd  同意、拒绝、共享视角关系与清理
  navigation/navigation_rules.gd   中立障碍数据、AStar 寻路、边界和视线
  audio/sound.gd                  环境声、动作音效、静音
worlds/
  lantern_inn/room.gd / room.tscn   旅店程序几何、11 处家具和 4 面边界碰撞
  lantern_inn/raid_view.gd          镜头/灯光、快照到角色/物品/尸体、视野限制
  prototype_room/                 旧地图入口的兼容继承，无第二套实现
ui/
  hud.gd                          大厅、行囊、同行者、手册和结算界面
  widgets/                        meter、minimap
assets/                           外置角色图和音频，不入 Git
addons/godot_ai/                   原有插件，保持原样
tests/                           model、companion、migration、integration、network
tools/                           素材还原、程序音效生成、网络测试启动
docs/                            分类设计、计划、任务、素材与验证记录
.references_code/                 只读参考和迁移前备份，排除导入与 Git
```

运行文件英文 snake_case；新模块按功能聚合，中文文档放 docs 分类目录并带日期。`.gd.uid` 跟随脚本保留；新脚本的 UID 由 Godot 生成。素材 `.import` 随外置素材交接，缓存不提交。

主入口不实现怪物/库存规则；match 不找 HUD/地图节点；inventory_rules 接受中立数组与容量；UI 只提出意图。权威推进调用各系统，所有系统共用本局唯一状态，不各存一份最终库存。

地图仍为程序搭建的手工布局，静态编辑器不会列出全部装饰；F6 查看地图，F5 跑完整游戏。真实移动碰撞由 player 的 CharacterBody3D 和地图 StaticBody3D 承担；纯模型测试的矩形求解是规则夹具，不替代实景物理验证。

公开契约见[设计与边界](2026-10-18-原型范围与模块边界.md)，迁移路径与参数变化见[迁移对照](../plans/2026-10-18-队长初稿迁移与复刻.md)。
