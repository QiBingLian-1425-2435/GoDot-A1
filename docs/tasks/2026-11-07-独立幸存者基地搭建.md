# 独立幸存者基地搭建

任务：按用户参考图使用其提供的33个GLB搭建新基地，旧基地保留。

范围：独立可见美术场景 worlds/survivor_base/survivor_base_preview.tscn；不替换原主场景、不改既有交互/联机地图协议。当前为布局展示，未接入NPC交易、医疗和出发交互。

原始模型保持不动；tools/prepare_survivor_base.py 在 Blender 中制作单件约18000面的副本，贴图压缩为1024像素，保存到外置 assets/worlds/survivor_base。素材名称映射、来源SHA256、原面数与优化面数在外置清单内。缺失的铁砧、工具挂板、地图和远景废楼用同色系简洁几何补充。

布局：后方城市大门与集合区，西北宿舍、西侧医疗、西南商铺，东北仓储、东侧铁匠、东南管理，前侧厨房/水电，中央炉火与公共桌椅。通道留空、前墙剖低。

预览：Godot打开独立场景运行；滚轮缩放、右键拖动旋转、中键拖动平移。命令行可用 -- --capture=绝对截图路径 --size=34 --point=0,0,0。

验证状态：本地完成。
