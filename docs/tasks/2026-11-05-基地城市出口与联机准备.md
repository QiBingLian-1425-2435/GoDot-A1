# 基地城市出口与联机准备

状态：本地实现和专项验证完成，Steam 双机异地待验。

## 用户需求与边界

- 移除门口梯子，基地大门改为进入现有城市，不再进入零号区；合并原侧边城市交互点。
- 联机时左上角显示准备人数/当前人数。靠近门按交互键确认准备，再按取消，全员准备后由房主统一切图。
- 单人一次交互直接进入城市。准备无需一直站在门前，但确认/取消均要求靠近门；队伍加入或退出清空准备，防止人员改变造成意外出发。
- 切图清空准备；不存档准备标记。城市撤离继续沿用全员存活撤离规则。

## 实现接口

- 复用 travel 意图，route=bunker_to_city，沿原房主身份、距离、高度与地图可用性验证。state.departure_ready 以成员 ID 保存布尔值，可靠状态快照同步。
- world_travel 负责准备判定和切图；base_model 在队员变化时清空标记；Main/HUD 只读取状态显示准备提示与计数。
- bunker 保留唯一大门交互和现有高亮目标，删除梯子杆与横档，world_flow 配置城市出生点。
- 兼容协议升级 a1_bunker_v29，所有成员使用同构建。无需新增运行素材。
- 零号区保留测试专用 surface_test_entry 路由夹具，既有地图测试不再依赖已移除的玩家入口。

## 验证

- 静态：资源导入、文本审计与 diff 检查。
- Headless：departure_ready_test 覆盖远距离拒绝、准备/取消、全员出发、重复请求、名单变更、资源缺失、单人进入。
- 可见：departure_scene_test 使用真实 Main，验证大门城市目标、门描边、E切换准备、左上角1/2、最后一人准备后实际城市加载；中英截图在 artifacts/departure_zh_CN.png、departure_en.png。
- 同机双进程：departure_network_test 真实 Session/RPC，客机准备/取消、房主准备、客机完成准备后双方切图，revision 仅递增一次。
- 本地化：中英审计、localization 三项套件通过；新提示在中英实景检查。
- 关联回归：interaction_outline_test 通过；Ground Zero 同机双进程完整往返房主10项/客机8项通过。其余改用测试入口的旧地图专项未逐项重跑，已完成编辑器解析检查。
