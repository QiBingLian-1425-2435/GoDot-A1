# 受击五秒追踪攻击者

## 状态与行为

完成本地实现、headless 规则、同机 ENet 多进程及城市实景回归。Steam 双机异地未执行。

- 房主确认敌人受到枪械、近战或投掷范围伤害后，立即锁定实际攻击者并记录五秒截止时间，朝向攻击者。包括原无敌病鬼命中。
- 五秒内每次更新追踪攻击者当前位置，不要求视线、朝向、普通视距或出生点追击范围。烟雾也不取消这段受击追踪；这覆盖旧烟雾规则中对受击敌人这五秒的普通视野限制。
- 保留之前受击停顿和近战击退，结束后继续追击。原物理碰撞仍有效，不能穿墙移动或隔墙攻击；靠近且攻击视线畅通时继续正常攻击。
- 新命中刷新五秒并切换到最新攻击者；持续燃烧的有效伤害脉冲也会刷新。五秒到期恢复原视野选择，不附加额外两秒盲追记忆。
- 攻击者死亡、成为灵魂或离线时取消强制追踪；死亡敌人不会接受新仇恨。离开地图仍沿原流程清空敌人。
- 状态由房主维护，客户端只显示已确认的移动。原敌人运动包格式不变，仇恨字段经完整快照同步；协议升级 `a1_bunker_v43`，联机双方必须更新。

## 实现

- `enemy_rules.gd`：`provoke` 记录来源与截止时间，`forced_target` 在受击停顿/攻击计时之前更新目标；目标选择优先这段强制追踪，再回退普通视野逻辑。
- `combat_system.gd`、`melee_system.gd` 传入真实玩家 ID；`throwable_system.gd` 使用房主记录的投掷者 ID，不接受客户端指定仇恨目标。
- 不调整伤害、移速、动画、声音、背包、地图和已有碰撞。
