# 开始界面分辨率与全屏设置

## 状态与范围

已完成本地实现和验证；未推送远端。本任务只调整本机显示偏好与输入接线，不修改网络协议、房间状态、地图、动作或外置美术。

- 开始界面和暂停菜单的“设置 → 音频与显示”新增窗口分辨率下拉框。提供 960×540、1280×720、1366×768、1440×810、1600×900、1920×1080、2560×1440、3840×2160 中适合当前屏幕工作区的选项；保留当前自定义尺寸，避免将窗口放到屏幕外。
- 全屏使用显示器原生分辨率，期间窗口分辨率控件明确禁用；退出全屏恢复已选窗口大小、边框并居中。分辨率是窗口尺寸选项，不宣称改变显示器物理模式或另加渲染比例。
- 全屏按钮只发出本地意图，由 main 接线给 `features/settings/display_settings.gd`，消除 UI 和 main 重复设置窗口的路径。识别普通和独占全屏。
- F11/自定义全屏绑定通过 HUD 统一处理，开始界面、游戏和暂停中都有效；按键重绑定捕获优先，避免录入 F11 时意外切换窗口。控件跟随实际窗口模式刷新。
- 分辨率和全屏偏好保存在 `user://video_settings.cfg`，重启读取。与原 `display_preferences.cfg` 中的速度/连跳显示设置互不覆盖。
- 新中英文文案通过现有 Texts 接口绑定，即时切换保留所选尺寸和窗口状态。

## 原问题调查

- 修改前独立窗口基线 `artifacts/display_baseline.log`：1440×810 窗口点击全屏后为 mode=3、2560×1440，关闭后回 mode=0、1440×810。未在独立窗口复现原按钮完全无效，因此不把它描述为已证实的引擎错误。
- 旧设置不持久化，F11 受 `in_game` 限制、开始界面无效；UI 和 main 都直接设置模式，没有统一的状态接线。
- Godot 4.5 官方明确指出编辑器内嵌运行不支持修改窗口模式/标记：https://docs.godotengine.org/en/4.5/classes/class_engine.html#class-engine-method-is-embedded-in-editor 。内嵌时现在禁用相关窗口控件并显示关闭“嵌入游戏”、独立运行的提示，避免开关看似已生效。没有改动本机编辑器偏好或插件。
