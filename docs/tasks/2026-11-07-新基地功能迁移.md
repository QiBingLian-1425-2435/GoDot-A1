# 新基地功能迁移

状态：已实现并完成本地分层验证；Steam双机异地未验。

## 行为与边界

新幸存者基地作为正式 bunker 地图，在初始单人/房主基地和城市撤离返回时加载。旧 worlds/bunker/bunker.gd 保留，世界ID、存档路径和房间资产规则不变。

迁移仓库、商人买卖、铁匠制作、医生休息恢复、管理员营地升级、训练靶重置、弹药补给和大门准备出发；营地自动恢复、背包、角色外观、存档继续沿原模块。准备/取消与全员进城仍由房主确认。

worlds/survivor_base/playable_base.gd 继承独立美术场景，提供八个交互点、玩家出生区、边界、家具和围墙实体碰撞、训练靶表现及本地交互描边目标。棚架仅柱子碰撞，门前地砖压平。出生点沿用(-1,4)，避免破坏既有单人和房间生成约定。城市返回仍沿原生成点与全员撤离规则。

Main和WorldFlow改用新基地；新地图采用原预览的暖色环境光。协议升级a1_bunker_v30，拒绝与旧碰撞布局混用；新增运行依赖进入bunker_sources清单。没有新增玩家文案，沿用现有中英键。
