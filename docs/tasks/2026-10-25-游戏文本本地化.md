# 游戏文本本地化

2026-10-25；任务 TEXT-001；实现分支：`fork`；状态：本地实现与验证完成。用户要求所有游戏文本统一存入静态文件，支持本地化管理；新增与修改保留在 fork 分支，仅本地提交。

- 范围：app、features、ui、worlds 内玩家可见文本，以及运行场景、窗口标题、物品定义、基地标牌、地图和联机通知；插件、日志、协议字段、资源路径和玩家自行输入的名字不作为翻译文本。
- 静态目录按稳定 key 管理，记录来源上下文；默认简体中文，支持语言选择、缺译回退和格式参数校验。
- 定义与共享状态保存语言无关引用；通知保留模板与参数，接收端展示时翻译。语言偏好仅保存在本机，不修改房主玩法状态。
- 本轮集成人统一修改 Main、Session、工程配置与打包白名单；不修改网络动作、库存或地图规则。
- 验收：文本覆盖审计、目录与参数校验、Godot 解析、中文默认显示、切换语言、缺译回退、动态参数、物品与地图文本、真实 UI 和接收端通知验证；分别记录 headless、可见界面、同机多进程与双机异地执行情况。

已实现 607 条静态中英文文本、即时语言切换、本机偏好、缺译/格式回退、接收端通知翻译与来源/导出审计。协议 v16。接口见[设计](../design/2026-10-25-游戏文本与本地化.md)，实际命令、分层结果及未测项见[验证记录](../verification/2026-10-25-游戏文本本地化验证.md)。
