# 全员存活撤离与友伤

2026-10-25，当前 AI 负责实现、公共协议调整和集成验证。用户指定 `fork` 分支，仅本地提交。状态：实现及本地自动验证完成，真实 Steam 双账号双机异地与人工可见撤离试玩待验。

- WorldTravel.travel 在探索地图前往 bunker 时检查所有存活成员：距发起者所用的同一撤离点不超过 2.4 米，高度差不超过既有交互高度 3 米。边界留 0.0001 米浮点误差容限。任何活人未到场则拒绝并发送可翻译通知，不切图、不缓存地图；到齐后玩家再次互动即可整队返回，不新增自动撤离或倒计时。
- 死亡灵魂及已断线成员不阻止撤离。尸变继续遵守原有禁止携带撤离规则；可复活、自杀，或由队友开枪击杀进入灵魂状态。回营地继续恢复灵魂，遗体与装备留在原地图缓存。
- Combat._fire 在探索地图使用房主确认的位置、瞄准、武器伤害和射击冷却，选中射线前方最近的队友身体；半径使用 PLAYER_RADIUS，高度按枪口中心差不超过 0.8 米。地图射线、规则障碍、较近靶子及较近队友挡住后方目标。只伤害一个目标，不伤害射手、灵魂或其他楼层队友。存活者正常扣 HP，归零转灵魂；尸变者 HP 已为 0，中弹转灵魂。营地训练不开队友伤害。
- 沿用 Session 现有 move/fire/travel 意图、身份校验和快照，无新增客户端伤害指令。shots 增加 hit_player_id，队友命中的 target_id 为 -1，避免和靶子编号混淆。Steam 协议更新为 a1_bunker_v17，依赖清单同步；不增加运行文件或变更存档格式。
- 普通 surface/cave 切图、同图个人传送、基地出发保持既有规则。enter_world 是内部整队切图入口，不用于客户端绕过撤离检查。

范围：world_travel、combat_system、Steam 协议版本、中英通知和来源索引、依赖协议字段、测试入口、相关文档。Main、快捷键任务、插件、素材和其他未提交成果保留。旧地表网络测试将房主也放到撤离点，符合新规则。

验证入口：`python tools/run_base_tests.py --suite extraction --godot "Godot 4.5.2 console 实际路径"`。过程和限制见[验证记录](../verification/2026-10-25-全员存活撤离与友伤验证.md)。
