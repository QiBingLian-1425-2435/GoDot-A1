# 录制脚步声替换与柔化

## 行为与状态

- 使用 Kenney Impact Sounds 1.0 中五段 concrete 脚步录音，替换运行时重复的白噪声脚步；来源 https://kenney.nl/assets/impact-sounds ，许可 CC0-1.0。
- 70 Hz 高通、2400 Hz 低通，约 3/6 ms 起止淡化；各段 RMS 上限 0.065、峰值上限 0.55，保留录音鞋底落地质感。
- 每步随机选择且不连续重复，音高仅 0.97–1.03、音量变化 ±0.6 dB；走路 -17 dB，跑步 -14 dB。
- 沿用原节奏：走路 0.39 秒/步，跑步 0.24 秒/步；沿用输入过滤，蹲行、灵魂与顶墙静止无脚步。不修改移速、动作、网络及枪击音效。
- 仍为原有本机脚步播放路径，不新增远端脚步同步。

- 音频位于 `assets/audio/footsteps/concrete_00.wav` 至 `concrete_04.wav`，同目录 `license.txt` 保留原许可、`manifest.json` 记录每文件大小、SHA256、来源与处理参数。
- 下载包 SHA256：`029d734af1582474edf3a694d1b0cebc97c1c152f2f39fa34d4c2bafc5de77f8`。下载缓存位于 `artifacts/dependencies/kenney_impact_sounds.zip`，不提交 Git。
- 还原：`python tools/prepare_footstep_audio.py --ffmpeg "实际的 ffmpeg 可执行文件路径"`。脚本仅使用 Python 标准库与本机 FFmpeg，校验源包后处理。首次下载需联网。
- 原版免费下载通过网站提供的下载链接接口获取。处理后的 WAV、许可及 manifest 继续走外置素材渠道；Git 仅包含脚本和依赖说明。
- `docs/dependencies/2026-10-19-bunker_sources.json` 登记音频与清单，Steam 打包会校验并复制这些文件；缺音频时会提示还原且不回退到刺耳的白噪声。
