# 常规快捷键配置

2026-10-25，KEYS-001，分支 `fork`。状态：本地实现与验证完成。

目标：设置提供移动、冲刺、蹲行、翻滚、开火、瞄准、互动、救援、换弹、背包、地图、武器切换、快捷消耗品、保存和全屏的配置。支持键盘和鼠标键、冲突拒绝、Esc 取消、恢复默认和跨进程本机持久化。默认背包保留 Tab / I，重绑替换为所选单键；Esc 菜单与滚轮缩放固定，不支持组合键和手柄。

配置归属本机 `user://key_bindings.cfg`，不写入房主共享状态、房间存档或协议。玩家输入仍发送既有意图，由房主验证。损坏或冲突配置整体回退默认；保存失败保留原配置。中英文静态文本入现有本地化目录。操作说明入口复用当前配置列表，HUD 和互动提示显示当前按键。

文件范围：玩家输入与本地按键偏好、设置面板、HUD、主入口的互动提示一处、本地化、依赖清单及专项测试。本次由当前 AI 单独集成，不修改网络、地图或插件；原有无关 UID 保留。仅本地提交到 fork，不合 main、不推送。

验收：实际 UI 重绑、旧键失效与新键生效、冲突与取消、恢复默认、跨进程读取、弹窗阻断玩法、中英文显示、现有输入回归。验证记录见 ../verification/2026-10-25-快捷键配置验证.md。
