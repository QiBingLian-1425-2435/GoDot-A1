# 六款近战武器与往返挥击

2026-11-08；状态：本地实现与分层自动验证完成，未执行 Steam 双机异地验收。

## 玩家行为

- 六款独立武器：消防斧 fire_axe、撬棍 crowbar（用户钩状工具）、棒球棍 baseball_bat、伸缩警棍 baton、开山刀 machete、日本刀 katana。可从商店购买，在现有武器槽装备，支持拖到 1–8 快捷栏及现有存档。
- 正常待机右手单持，左手自然放下；走跑沿用原动作摆臂。右键使用现有 ads 输入，双手举至右胸前，松开平滑回到单持。
- 左键短按立即挥击；未按右键时为单手挥击，按住右键时双手挥击。连续点击或按住左键，在前挥和回挥间交替。后段只缓存一个攻击，拒绝叠加伤害；打开背包、失焦等继续沿用输入阻断。
- 不消耗子弹、不装弹、不产生枪口火光与弹道。HUD 显示近战和无需弹药；补充双语名称、说明和六种物品图标。
- 男女角色共用握柄适配，手腕朝向保留导入骨骼缩放。原模型没有手指骨骼，沿用现有手部网格。

## 规则、接口与归属

- `features/combat/melee_system.gd` 为房主规则，经现有 fire 意图进入；不新增 RPC。挥击中段（持续时间 42%）结算一次前方 120 度、按武器距离限制的命中，检查高度差、二维障碍和真实三维遮挡。
- 继承现有伤害、击退、无敌及探索友伤规则，基地内不伤队友。死亡、换武器、跳跃、换地图、地图未就绪和其他动作覆盖时取消未结算攻击；地图加载后不残留攻击。
- 复用已有 anim_seq、anim_action、anim_time、anim_duration 同步前挥/回挥。瞬时规则状态 melee_attack、melee_buffer 不进入人物存档。
- `features/player/animation/melee_pose.gd` 提供右手携带、双手握持、左右往返路径；导入动画代理使用既有双臂 IK，表现不决定命中。
- 新物品与战斗规则要求相同构建，协议更新为 **a1_bunker_v35**；不修改玩家移动速度、原走跑动画资源或地图布局。
