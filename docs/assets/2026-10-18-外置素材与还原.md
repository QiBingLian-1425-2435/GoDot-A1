# 外置素材与还原

更新：2026-10-18。素材已完整迁入根工程 `assets/`，这是当前正式素材目录；运行、校验和素材交接均不依赖 `.references_code/123/`，参考区后续可以清理。队长初稿仅作为历史来源，没有复制源码工程的缓存、插件或编译包。

三张 PNG（hero、companion、monster）和七个 WAV（ambient、danger、down、extract、pickup、rescue、step）的长度与 SHA256 见 [assets_manifest](2026-10-18-assets_manifest.json)。角色原图及声音均与初稿逐字节一致。角色导入保留 mipmaps，素材及 `.import` 不入 Git。

在项目根 PowerShell 执行：

```powershell
# 校验项目 assets/ 内的全部素材，不读取参考区
./tools/restore_assets.ps1
# 其他电脑先取得队长的外置素材目录（其下应有 characters 和 audio）
./tools/restore_assets.ps1 -SourceDirectory 'D:/external/lantern_assets'
```

不传参数时仅校验项目 assets/ 的完整性；指定外部 SourceDirectory 时先校验全部来源散列，再复制到 assets。打开根工程等待 Godot 导入后运行。向成员交接素材时直接打包当前根工程 assets/（包内保留 characters/、audio/ 和导入旁文件），无需保留原参考工程。本轮没有远端上传素材或创建共享下载地址。

角色生成记录见[角色来源](2026-10-18-角色生成来源.md)，原接入说明保留为[历史记录](2026-10-18-初稿角色接入记录.md)，其中 game/ 路径属于初稿，现行路径见项目结构。音效原说明见[音效来源](2026-10-18-初稿音效来源.md)；可用 `python tools/generate_audio.py` 重生成（依赖 numpy）。重新生成后需比对清单，不能冒充原包。

原有 addons/godot_ai 本轮未修改或用初稿副本覆盖；分发代码时由团队继续外置交接插件。现有 Windows 试玩包属于初稿旧构建，不能作为当前迁移代码的运行或验收证据。

## 团队同步建议（2026-10-18）

当前正式素材目录为根工程 assets/characters 和 assets/audio；三张角色图、七个音频共 5,380,241 字节（约 5.13 MiB），另有本机生成的导入旁文件。参考原件只是冗余副本，不承担还原职责。整个 assets/ 已排除 Git，不依赖扩展名判断；docs/assets 下的来源说明和 SHA256 清单保留在代码仓库。

本轮已对根工程十个素材逐一校验 SHA256 并通过；素材文件保留在本地项目，不加入 Git，也未上传。

建议代码通过 GitHub 同步，素材使用团队已有共享盘/网盘或 NAS，按版本发布不可覆盖的素材包，例如 lantern_assets/2026-10-18-v1/，包内固定 characters/ 和 audio/ 相对路径。不要让多人直接同步整个 Godot 工作目录或 .godot 缓存。

素材负责人更新共享包后，同一代码提交更新素材清单、素材版本与共享链接，再由成员下载并运行 restore_assets.ps1 校验和还原；新增素材先更新脚本读取的清单。共享服务和访问链接尚待团队选择，本轮没有创建共享盘或上传文件。Godot AI 插件继续单独外置交接，不混入上述十个素材的清单。

当前项目规则明确美术/二进制不入 Git、不用 LFS 绕过，因此不建议另外建一个普通 Git 素材仓库；这仍会积累二进制历史。以后若想改用 Git LFS，需要团队明确修改现有约定。GitHub 官方也建议通过其他方式分发大文件：[About large files on GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。
