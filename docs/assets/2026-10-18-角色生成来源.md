# Character sprites

Generated with built-in image_gen in generate mode, with transparent_background=true. No reference image was submitted as an edit target. Generated originals were copied into this project unchanged; alpha was preserved. All three images were inspected visually and are complete single-character cutouts with no text or scenery.

These are static idle art assets. Motion should be implemented with Sprite3D transforms and directional flip, not presented as a generated walk-cycle.

## Prompts

### hero.png

```text
Use case: stylized-concept
Asset type: single transparent cutout sprite for a 2.5D fantasy game, meant to be read at 100 pixels tall.
Primary request: One adorable youthful adventurer, idle standing pose, full body, slightly three-quarter frontal view. Messy auburn-red hair, big round head, mildly determined friendly face, tiny body, two-heads-tall chibi proportions. Wears a short deep teal-green cloak, cream tunic, dark trousers, chunky brown boots and a small leather cross-body satchel. Arms resting naturally, no weapon.
Style/medium: hand-drawn storybook paper-doll cartoon. Broad dark sepia ink outlines, charming simplified facial features, muted warm colors, subtly textured flat paint with restrained cell shading. Strong clean readable silhouette. Fantasy cozy adventure tabletop illustration. Not pixel art, not a 3D render.
Composition/framing: exactly one character centered on square canvas, full hair and both boot soles visible, character occupies about 82 percent of height, straight vertical body axis and feet aligned on a common baseline near 90 percent of canvas height.
Scene/backdrop: genuinely transparent alpha background, only the character visible. No ground shadow.
Constraints: no background, no scenery, no white box, no checkerboard, no glow, no text, no nameplate, no watermark, no border, no alternate views, no extra people, not a sprite sheet.
```
