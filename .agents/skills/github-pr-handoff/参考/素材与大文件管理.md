# 素材与大文件管理

本页独立包含当前团队素材交付规则，不依赖其他项目文档。实际用户明确改变策略时按新策略调整，不悄悄改用 LFS。

## 保存范围

GitHub 保存代码、文本场景/定义（`.tscn`、`.tres`）、配置、文档与脚本 `.uid`。图片、贴图、音视频、模型、字体、美术源文件、二进制 `.scn/.res`、压缩包和导出包不上传。`.vscode/`、`.idea/`、`.codex/` 以及 `.agents/` 中除项目级 `.agents/skills/` 外的本机工具配置也排除。

本包 [忽略模板](../模板/.gitignore) 可用于新仓库；已有 `.gitignore` 时先比较合并，不覆盖用户其他规则。技能既可放在本机全局技能目录，也可作为项目级工作流提交到 `.agents/skills/`。

`.gitignore` 不能按大小过滤，也不影响已跟踪文件。单文件达到 **10 MiB（10,485,760 字节）**默认视作大文件；素材不论大小都外置。陌生二进制/新后缀仍需人工或 AI 根据任务识别，不因脚本未识别就允许上传。

## 运行只读检查

本包 [检查提交内容.py](../脚本/检查提交内容.py) 只需 Python 3 和 Git，不依赖 pip 库、作者目录或其他技能。以下以已安装于项目 `.agents/skills/` 为例；个人安装时把脚本路径换成实际安装位置，`--repo` 指实际仓库。

```powershell
python -X utf8 .agents/skills/github-pr-handoff/脚本/检查提交内容.py --repo . --scope staged
```

暂存后、commit 前检查暂存区；本地提交、fetch 和 rebase 后，推送前检查完整待交付历史：

```powershell
python -X utf8 .agents/skills/github-pr-handoff/脚本/检查提交内容.py --repo . --scope outgoing --base origin/main
```

退出码：0 表示路径/大小检查通过；1 表示发现排除项/大文件；2 表示检查未完成或环境/基线不满足。脚本不暂存、不提交、不改配置、不联网、不 push，也不会删除任何文件。运行它不代表已安装 hook 或 CI。

`staged` 检查本次暂存 blob 的大小，而非工作区当前字节；`outgoing` 检查基线之后每个提交引入/修改的路径和 blob。先提交大文件再删除，仍会发现旧提交中的内容。未先 rebase 到选定主线、未解决冲突或子模块变更会要求先处理，不冒充检查成功。

没有 Python 时，可用 Git 完成等价只读检查：

```powershell
git diff --cached --name-only -z
git ls-files --stage -z
git rev-list --reverse origin/main..HEAD
git diff-tree --root --no-commit-id -r -m --name-only --diff-filter=ACMR -z 实际提交SHA
git ls-tree -r -z --full-tree 实际提交SHA
git cat-file -s 实际blobSHA
git check-ignore --no-index -v -- 实际路径
```

按每个真实提交和对应 blob 检查后缀、目录与大小，不只看最终 diff。`-z` 输出需要按 NUL 解析，不能用普通逐行方式处理特殊路径。检查实际完成才报告通过。

## 检查失败怎样处理

- 已暂存但不应提交：只撤销本任务确定路径的暂存，保留工作区字节，不影响他人暂存。
- 已跟踪素材：列明具体路径，对确定文件用 `git rm --cached -- 实际路径` 停止后续跟踪，保留本地；不全库清空索引。
- 本人独立、未交付历史已有违规内容：整理这段本地历史，把内容从待上传提交中移除，再重新检查和验证。新增一条删除提交不能代替历史清理。
- 涉及已共享/远端历史：说明影响与后续方案，不顺手重写共享历史或强推 main。

## 队友取得素材

团队选择仓库外共享渠道。维护者在真实任务或项目说明中写清素材包版本、获取位置、校验值/大小、来源/许可、英文目标路径与对应代码版本；技能不自动建网盘或上传素材。

clone 后可能需要先补素材才能运行。相同版本落到相同 `res://` 路径，接收端重新导入并验证引用。脚本 `.uid` 保留；素材 `.import` 旁文件不入 Git，需要固定的导入参数用说明或可重复步骤交接，不能假定默认重导入一定还原画面。

官方依据：[Git 忽略规则](https://git-scm.com/docs/gitignore)、[Godot 版本控制](https://docs.godotengine.org/en/stable/tutorials/best_practices/version_control_systems.html)。工程素材外置是本团队的选择，需要额外维护版本同步。
